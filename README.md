# hackerman
Hackerman Singularity Terminal v10: um sistema operacional web retrô-futurista com estética cyberpunk, terminal interativo real, IA integrada com personalidades, janelas flutuantes, cofre encriptado, editor de código, jogos (snake, pong, blackjack), chat multiplayer entre abas e 15 temas visuais. Tudo em HTML, CSS e JavaScript puro.
